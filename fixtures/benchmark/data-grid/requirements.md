# Data Grid Requirements

## Acceptance criteria
- REQ-1: Search filters rows by customer name.
- REQ-2: Status filtering shows only matching rows.
- REQ-3: Sorting by amount toggles ascending and descending order.
- REQ-4: Pagination changes the visible result set.
- REQ-5: Refresh updates the table status using a local API-like update.

## Capabilities
- CAP-1: Search and filter.
- CAP-2: Sort dynamic table.
- CAP-3: Paginate results.
- CAP-4: Refresh API-driven status.

## Constraints
- CON-1: Empty result sets display No results.
