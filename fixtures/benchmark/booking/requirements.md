# Room Booking Requirements

## User roles

- customer

## Capabilities

- Search available rooms.
- Book an available room.
- Cancel an existing booking.

## Acceptance criteria

- A customer can search for available rooms.
- A customer can book an available room.
- A successful booking shows a confirmation.
- An unavailable room cannot be booked.
- A customer can cancel an existing booking.

## Constraints

- A room must be available before it can be booked.
- The same room cannot be booked twice for the same date.
