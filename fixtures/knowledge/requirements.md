# Booking System

## User Roles

- Customer
- Admin

## Functional Requirements

- Customers can search available rooms.
- Customers can create a booking.
- Admins can manage rooms.

## Acceptance Criteria

- A customer can book an available room.
- A booking confirmation must be shown after a successful booking.
- An unavailable room must not be bookable.

## Constraints

- A booking must belong to a customer.
- Only admins can delete rooms.
- The system must not create duplicate bookings for the same room and date.
