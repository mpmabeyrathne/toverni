# Example application requirements

## Capabilities

- A user can view the product list.
- A user can search products by name.
- A user can add an available product to the cart.
- A user can review the cart before checkout.

## Acceptance criteria

- Search results must contain the entered product name when a matching product exists.
- Unavailable products must not be purchasable.
- Cart quantity must be visible after an item is added.
- Checkout must require an email address before continuing.

## Constraints

- Destructive account or payment actions must not be executed during autonomous exploration.
